# River Room OA州Token

一个支持局域网多人联机的 Texas Hold'em（OA州Token）游戏。Node.js 服务端负责洗牌、发牌、下注回合、AI 行动和牌局结算，玩家通过浏览器或 Windows 玩家客户端加入同一张牌桌。

## 主要功能

- 服务端统一管理牌堆、回合和结算，玩家只能看到自己的底牌
- 玩家可注册账号并使用密码登录，账号、登录状态与 Token 余额由服务器持久保存
- 登录后进入服务器大厅，可创建多个自定义名称的公开或密码房间
- 房主可增减 AI 机器人，并邀请同一服务器上的其他账号免密码加入
- 支持弃牌、过牌、跟注、加注和行动超时
- 空位自动由会随机下注的 AI 玩家补齐
- 最多五名真人玩家加入同一桌
- 提供服务器设置页面，可管理 Token、盲注和下注范围
- 提供服务器客户端和玩家客户端 Windows 便携包
- 不依赖数据库，牌桌规则会保存在本地 JSON 文件中

## 直接启动服务

建议使用 Node.js 18 或更高版本。项目没有第三方依赖，不需要运行 `npm install`。

```powershell
node server.js
```

启动后可访问：

- 玩家牌桌：`http://localhost:3000`
- 服务器设置：`http://localhost:3000/server`

首次使用先注册账号，之后可直接使用账号和密码登录。浏览器会保留 30 天登录状态，服务器重启后仍可自动恢复账号和 Token。进入自己创建的房间后，可以按需要添加 AI 玩家。

## 房间大厅

- 登录后可以创建房间，房间名称长度为 2-24 个字符
- 房间密码可留空；设置密码后，未受邀请的玩家加入时必须输入密码
- 房主可以在房间内添加或删除 AI 机器人，调整会在安全的牌局节点生效
- 房主可以邀请服务器上的注册账号，受邀玩家会在大厅看到邀请并可免密码加入
- 同一账号同一时间只能进入一个房间，最多五个真人与 AI 座位
- 进行中的一手牌结束后才可主动退出房间，避免中途退出造成 Token 结算错误

房间和邀请是服务器运行时数据，重启服务后会清空；玩家账号和 Token 余额仍会保留。

### M 房

服务器会自动保留一个独立的 `M房`，玩家不能通过普通的开房表单创建或改名占用它。M 房在大厅中单独显示，加入前会明确说明：

- M 房提示为“本房间为实验性高价值房间，慎入。”
- M 房的输赢会正常计入玩家账号的正式 Token
- 普通房间不读取 M 房的实验参数，仍使用随机发牌
- 玩家必须勾选确认后才能加入，服务端也会再次校验确认字段

管理员可以在服务器设置右上角的 `M` 入口中按账号设置大牌概率和小牌概率，剩余概率保持随机。参数仅保存在服务内存中，服务重启后自动清除；详细变更只写入服务器控制台日志。

## 玩家账号

- 账号长度为 2-20 位，可使用中文、字母、数字和下划线
- 密码长度为 6-72 位
- 密码使用随机盐和 `scrypt` 哈希保存，服务器不会保存明文密码
- 账号资料保存在 `data/accounts.json`
- 登录签名密钥保存在 `data/auth-secret.txt`
- 每手牌结算后会保存真人玩家的 Token 余额

`accounts.json` 和 `auth-secret.txt` 已加入 `.gitignore`，不会被提交到 GitHub。迁移服务器时需要一起备份这两个文件，否则原账号或已登录会话将无法继续使用。

## 服务器设置

默认管理员密码为：

```text
riverroom-admin
```

在共享网络中使用前，建议设置自己的管理密码：

```powershell
$env:ADMIN_PASSWORD = "你的管理密码"
node server.js
```

服务器设置页面支持：

- 查看监听端口、本机地址和局域网玩家地址
- 查看服务器运行时间和当前牌桌状态
- 给当前牌桌上的所有玩家和 AI 发放 Token
- 给指定账号单独发放 Token，账号离线时也会保存到服务器
- 设置新玩家的初始 Token
- 设置小盲注和大盲注
- 设置最低下注、每轮最高下注和最小加注幅度
- 查看玩家余额、下注额、在线状态和行动状态
- 查看已注册账号、账号 Token、在线状态和最近登录时间

牌局规则修改会在下一手牌开始时生效，设置保存在 `data/table-settings.json`。

## Windows 客户端

项目可以生成两个免安装的 Windows 便携包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

生成的文件位于 `dist` 目录。

### 服务器客户端

解压 `River Room Server Client.zip`，双击：

```text
River Room Server.cmd
```

服务器客户端内置 Node.js，会自动启动游戏服务，并以独立应用窗口打开“服务器设置”。端口和管理员密码可在服务器包中的 `server-config.ps1` 修改。

如果服务由服务器客户端启动，关闭服务器客户端窗口时，对应服务也会停止。如果客户端检测到已有服务，则只连接该服务，不会在关闭窗口时停止它。

### 玩家客户端

解压 `River Room Player Client.zip`，双击：

```text
River Room Player.cmd
```

输入服务器设置页面显示的“局域网玩家地址”即可加入牌桌。玩家客户端会记住上一次填写的服务器地址；连接服务器后可直接注册或登录账号。

两个客户端都使用 Microsoft Edge 的应用模式打开独立窗口。当前 Windows 10 和 Windows 11 通常已经自带 Edge。

## 局域网联机

启动服务器后，在服务器设置页面复制局域网玩家地址，例如：

```text
http://192.168.1.20:3000
```

让其他设备连接同一个局域网，并在浏览器或玩家客户端中打开该地址。Windows 防火墙首次提示时，需要允许 Node.js 访问专用网络。

## 默认规则

- 初始 Token：2,000
- 小盲注 / 大盲注：25 / 50
- 最低下注：50
- 每轮最高下注：2,000
- 最小加注幅度：50
- 自动行动超时和自动开始下一手牌
- 使用七张可用牌中的最佳五张进行标准牌型比较

## 当前限制

这是一个用于本地或局域网娱乐的原型项目，目前不包含：

- 忘记密码、邮件验证和自助修改密码
- 边池结算
- 公开互联网部署防护
- 任何真实货币支付或兑换功能

管理员密码与玩家登录相互独立。请勿将本项目直接用于真实货币游戏。
